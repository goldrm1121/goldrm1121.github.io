# goldrm1121.github.io

Hollis Li 的個人網站：雙語（EN / 中文）、three.js 互動天際線、載入百分比、Feather icons。

- `index.html` — 結構與英文內容
- `assets/i18n.js` — 中文翻譯（key 對應 `data-i18n`）
- `assets/scene.js` — 3D 天際線
- `assets/main.js` — 載入器、語言切換、互動
- `assets/style.css` — 樣式

本機預覽：`python3 -m http.server` 後開 http://localhost:8000 （`?enter` 跳過進入畫面，`?lang=zh` 指定語言）
內容需與 ~/Awesome-Sara/content-*.tex 同步，只放已查證的事實。
